# Rhythmix - Music Playlist Organizer

Rhythmix is a music playlist organizer built with React. It lets users browse songs, play previews, like songs, filter by mood, and generate playlists in a clean music-app style interface.

## Main Features

- Play, pause, previous, next, and progress bar controls
- Mood-based filtering
- Search songs by name or artist
- Like songs and view liked songs
- Recently played songs
- Top 10 songs by popularity
- Smart Mix and Quick Mix playlist generation
- Responsive design

## DSA Concepts Used

- **Max Heap** for Top 10 ranking
- **Dynamic Programming** for Smart Mix playlist generation
- **Greedy Algorithm** for Quick Mix playlist generation
- **Map** for mood grouping
- **Set** for liked songs

## Tech Stack

- React
- React Router
- CSS Modules
- Jamendo API
